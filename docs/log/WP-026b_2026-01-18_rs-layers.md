# WP-026b — RS layer expansion (2026-01-18)

## What changed
- Added JC/TAS analysis layers for canopy height (CHM), soil pH, WorldClim BIO1/BIO12, and TASVEG fire attributes.
- Added geology, land tenure, and reserve estate vectors (AOI-clipped) with preview PNGs.
- Added WMS/ArcGIS overlays for fire attributes and soil pH; TASVEG class legends now show AOI-only codes.
- Switched WorldClim downloads to tile-based fetches and optimized raster clipping (crop before reprojection) for performance.
- Added large-download gating (`data.large_downloads.allow`) with placeholder CHM outputs when disabled.
